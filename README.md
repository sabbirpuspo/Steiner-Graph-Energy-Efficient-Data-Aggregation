This research presents a novel framework, called Steiner-Graph Energy Efficient Da-ta Aggregation (SG-EDA), which optimizes energy efficiency in multi range wireless sensor networks (WSNs) using innovative data aggregation algorithm. The proposed model takes advantage of a graphical algorithm and Steiner tree principle to mini-mize energy consumption in transferring data from sensors to the sink node. How-ever, in traditional multi range WSNs data aggregation is a critical enabler for ex-tending network lifespan, but challenges such as variable transmission ranges and energy depletion have not been resolved. The researcher proposes an optimized Graphical Steiner tree-based aggregation process which selects relay nodes and data paths dynamically according to energy availability and transmission distance, and network topology. SG-EDA constructs minimal spanning trees specific to the net-work range diversity so that data is aggregated as efficiently as possible while saving the overall energy expenditure. The simulation results demonstrate that SG-EDA achieves competitive or favorable performance compared to existing data aggrega-tion protocols with respect to energy consumption, network lifetime, and data accu-racy. In particular, under the tested simulation configurations, SG-EDA reduced en-ergy consumption by approximately 20--30% and increased network operational time by up to a factor of 2 compared to baseline models. In addition, the framework is adaptable to various WSN configurations, offering a scalable and robust solution for the next generation sensor networks.
